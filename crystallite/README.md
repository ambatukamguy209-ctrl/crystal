# CrystalLite (Fabric, Minecraft 1.21.11)

Client-side end crystal helper:
- Instant Crystal Removal: hit a crystal and it disappears on your client immediately.
- Pace Crystal Placement (optional): limits how fast you can place crystals. It never places or breaks anything for you.
- In game: /crystallite opens the settings screen.

Build without installing anything: upload this folder to a new GitHub repo, open the Actions tab,
run "Build jar", and download the "crystallite-jar" artifact (use the jar without "-sources").
Put it in your mods folder together with Fabric API 0.141.x for 1.21.11.
